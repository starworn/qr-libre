# QR Libre Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Portable Windows `.exe` (Tauri 2) that generates styled, verified, never-expiring static QR codes and exports them as PNG (with sRGB/DPI metadata) or SVG.

**Architecture:** All QR logic lives in DOM-free TypeScript modules (`encode → render → verify`, plus `contrast`, `png-chunks`, `settings`, `export`) so Node tests and the gallery script use exactly the same code as the app. `render.ts` produces one SVG that is the single source of truth for preview, SVG export and PNG export. The Rust side is only the official `dialog` and `fs` plugins. GitHub Actions builds the Windows exe on tag.

**Tech Stack:** Tauri 2, Vite, TypeScript (no UI framework), `qrcode-generator`, `jsqr`, Vitest, `@resvg/resvg-js` (tests/gallery only), `pngjs` (tests only), `tsx` (gallery script).

**Spec:** `docs/superpowers/specs/2026-10-03-qr-libre-design.md`

## Global Constraints

- Platform target: Windows 10/11 x64, portable exe (no installer), built by GitHub Actions on `windows-latest`.
- Linux dev on NVIDIA + Wayland: run Tauri with `WEBKIT_DISABLE_DMABUF_RENDERER=1` (`launch.sh`).
- Default error-correction level: `Q`. Margin range 0–8 modules, default 4, warn below 2.
- Export sizes exactly: 512 / 1024 / 2048 / 4096 px. Print mode = 300 DPI.
- PNG always carries `sRGB` + `gAMA` + `cHRM`; print mode adds `pHYs` (300 DPI = 11811 px/m). Any pre-existing `iCCP`/`sRGB`/`gAMA`/`cHRM`/`pHYs` is removed first.
- Legibility rules warn, never block; exporting while verification is not `ok` asks for confirmation.
- UI language default Spanish, toggle to English; every key exists in both.
- License MIT. Repo `starworn/qr-libre`. Git identity in this repo: `starworn <kairumistarworn@gmail.com>` (already set locally). Do not push — pushing waits for the account-switcher task (separate).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Package versions available at plan time: tauri cli/api 2.12, plugin-dialog 2.8, plugin-fs 2.6, vite 8, vitest 5, typescript 7, qrcode-generator 2.0.4, jsqr 1.4, @resvg/resvg-js 2.6, pngjs 7. If a major version's API differs from the code below, adapt to the installed API and keep the tests' intent; if TypeScript 7 causes tooling trouble, pin `typescript@^5`.

## Review Focus

1. **Non-ASCII text** (`https://ejemplo.mx/café-ñandú`, emoji) must decode to the identical string → pinned in Task 2 (`encode` UTF-8 test) and Task 4 (round-trip URLs).
2. **Text too long for a QR** (e.g. 3000 chars at ECC H) must show a clear message, not crash or freeze → `TooLongError` test in Task 2; UI branch in Task 9.
3. **Empty / whitespace-only / trailing-newline paste** must show the "paste a URL" hint, disable export, and trim before encoding & verifying → Task 2 tests (`normalizeText`, `EmptyInputError`).
4. **Corrupt, old or hand-edited saved settings** (bad JSON, out-of-range numbers, unknown enums, `localStorage` throwing) must fall back to defaults/clamped values → Task 3 tests.
5. **User cancels the Save dialog** must silently do nothing (no error message, no write) → Task 8 `exportFile` test with fake deps.

```ts
  encode, normalizeText, isEyeModule, eyeOrigins, EmptyInputError, TooLongError, type QrMatrix,

// Minimal matrix → RGBA rasteriser (4 px per module, 4-module white margin) so encode can be
// tested without depending on render.ts.
function matrixToRgba(m: QrMatrix) {
  const scale = 4, margin = 4, n = (m.size + margin * 2) * scale;
  const px = new Uint8ClampedArray(n * n * 4).fill(255);
  for (let r = 0; r < m.size; r++)
    for (let c = 0; c < m.size; c++)
      if (m.modules[r][c])
        for (let y = 0; y < scale; y++)
          for (let x = 0; x < scale; x++) {
            const i = (((r + margin) * scale + y) * n + (c + margin) * scale + x) * 4;
            px[i] = px[i + 1] = px[i + 2] = 0;

  return { px, n };

  const { px, n } = matrixToRgba(m);

  return res ? new TextDecoder().decode(new Uint8Array(res.binaryData)) : null;
};
```

```ts
import qrcode from 'qrcode-generator';
import type { Ecc } from './settings';

// qrcode-generator defaults to Latin-1 byte conversion; switch to UTF-8 so ñ, é, emoji survive.
qrcode.stringToBytes = qrcode.stringToBytesFuncs['UTF-8'];

export class EmptyInputError extends Error {}
export class TooLongError extends Error {}

export interface QrMatrix {
  size: number;
  /** modules[row][col], true = dark */
  modules: boolean[][];
}

export function normalizeText(text: string): string {
  return text.trim();
}

export function encode(text: string, ecc: Ecc): QrMatrix {
  const t = normalizeText(text);
  if (!t) throw new EmptyInputError('empty input');
  const qr = qrcode(0, ecc);
  try {
    qr.addData(t, 'Byte');
    qr.make();
  } catch (e) {
    throw new TooLongError(e instanceof Error ? e.message : String(e));
  }
  const size = qr.getModuleCount();
  const modules = Array.from({ length: size }, (_, r) =>
    Array.from({ length: size }, (_, c) => qr.isDark(r, c)),
  );
  return { size, modules };
}

export function eyeOrigins(size: number): Array<[number, number]> {
  return [[0, 0], [0, size - 7], [size - 7, 0]];
}

export function isEyeModule(size: number, row: number, col: number): boolean {
  return eyeOrigins(size).some(([r0, c0]) => row >= r0 && row < r0 + 7 && col >= c0 && col < c0 + 7);
}
```
If `qrcode-generator@2` changed the UTF-8 hook (e.g. no `stringToBytesFuncs`), use whatever its README documents for UTF-8 byte mode; the non-ASCII test is the contract.

Rendering rules (from spec):
- viewBox is in module units: `0 0 total total`, `total = m.size + 2*margin`; code starts at `(margin, margin)`.
- Background `<rect>` only when not transparent; corner radius `= bgRadius * min(margin * 3.4, total/2)` (3.4·margin is the largest radius whose arc stays outside the code corner).
- All data modules go in **one** `<path>` (one path ⇒ no hairline seams between neighbours). Each corner radius `= moduleRadius * 0.5`, applied only where `roundableCorners` says the corner is exterior.
- Eyes go in one `<path fill-rule="evenodd">`: outer 7×7 (radius `eyeRadius*3.5`), hole 5×5 (`*2.5`), centre 3×3 (`*1.5`).
- Gradient uses `gradientUnits="userSpaceOnUse"` spanning the code area, so modules and eyes share one continuous gradient. Eye colour, when enabled, is solid.

```ts
import { eyeOrigins, isEyeModule, type QrMatrix } from './encode';
import type { Style } from './settings';

export interface Corners { tl: boolean; tr: boolean; br: boolean; bl: boolean }
export interface SvgSize { width: string; height: string }
interface Radii { tl: number; tr: number; br: number; bl: number }

const f = (n: number) => String(Math.round(n * 1e4) / 1e4);
const all = (r: number): Radii => ({ tl: r, tr: r, br: r, bl: r });

/** A corner is exterior when both orthogonal neighbours touching it are light (eyes count as light). */
export function roundableCorners(m: QrMatrix, row: number, col: number): Corners {
  const light = (r: number, c: number) =>
    r < 0 || c < 0 || r >= m.size || c >= m.size || !m.modules[r][c] || isEyeModule(m.size, r, c);
  const up = light(row - 1, col);
  const down = light(row + 1, col);
  const left = light(row, col - 1);
  const right = light(row, col + 1);
  return { tl: up && left, tr: up && right, br: down && right, bl: down && left };
}

/** Clockwise rectangle with per-corner radii (0 = square corner). */
function rectPath(x: number, y: number, w: number, h: number, k: Radii): string {
  let d = `M${f(x + k.tl)} ${f(y)}H${f(x + w - k.tr)}`;
  if (k.tr) d += `A${f(k.tr)} ${f(k.tr)} 0 0 1 ${f(x + w)} ${f(y + k.tr)}`;
  d += `V${f(y + h - k.br)}`;
  if (k.br) d += `A${f(k.br)} ${f(k.br)} 0 0 1 ${f(x + w - k.br)} ${f(y + h)}`;
  d += `H${f(x + k.bl)}`;
  if (k.bl) d += `A${f(k.bl)} ${f(k.bl)} 0 0 1 ${f(x)} ${f(y + h - k.bl)}`;
  d += `V${f(y + k.tl)}`;
  if (k.tl) d += `A${f(k.tl)} ${f(k.tl)} 0 0 1 ${f(x + k.tl)} ${f(y)}`;
  return d + 'Z';
}

function gradientDefs(m: QrMatrix, s: Style): string {
  const stops = `<stop offset="0" stop-color="${s.color1}"/><stop offset="1" stop-color="${s.color2}"/>`;
  const c = s.margin + m.size / 2;
  if (s.fillMode === 'linear') {
    const a = (s.gradientAngle * Math.PI) / 180;
    const dx = (Math.cos(a) * m.size) / 2;
    const dy = (Math.sin(a) * m.size) / 2;
    return `<linearGradient id="fg" gradientUnits="userSpaceOnUse" x1="${f(c - dx)}" y1="${f(c - dy)}" x2="${f(c + dx)}" y2="${f(c + dy)}">${stops}</linearGradient>`;
  }
  return `<radialGradient id="fg" gradientUnits="userSpaceOnUse" cx="${f(c)}" cy="${f(c)}" r="${f(m.size * Math.SQRT1_2)}">${stops}</radialGradient>`;
}

export function renderSvg(m: QrMatrix, s: Style, size: SvgSize = { width: '512', height: '512' }): string {
  const total = m.size + 2 * s.margin;
  const off = s.margin;
  const parts: string[] = [];

  if (!s.bgTransparent) {
    const rx = s.bgRadius * Math.min(s.margin * 3.4, total / 2);
    parts.push(`<rect width="${total}" height="${total}" rx="${f(rx)}" fill="${s.bgColor}"/>`);
  }

  const gradient = s.fillMode !== 'solid';
  const fill = gradient ? 'url(#fg)' : s.color1;

  const r = s.moduleRadius * 0.5;
  let d = '';
  for (let row = 0; row < m.size; row++) {
    for (let col = 0; col < m.size; col++) {
      if (!m.modules[row][col] || isEyeModule(m.size, row, col)) continue;
      const k = roundableCorners(m, row, col);
      d += rectPath(off + col, off + row, 1, 1, {
        tl: k.tl ? r : 0, tr: k.tr ? r : 0, br: k.br ? r : 0, bl: k.bl ? r : 0,
      });
    }
  }
  parts.push(`<path fill="${fill}" d="${d}"/>`);

  const e = s.eyeRadius;
  let ed = '';
  for (const [er, ec] of eyeOrigins(m.size)) {
    const x = off + ec;
    const y = off + er;
    ed += rectPath(x, y, 7, 7, all(e * 3.5));
    ed += rectPath(x + 1, y + 1, 5, 5, all(e * 2.5));
    ed += rectPath(x + 2, y + 2, 3, 3, all(e * 1.5));
  }
  const eyeFill = s.eyeColorEnabled ? s.eyeColor : fill;
  parts.push(`<path fill="${eyeFill}" fill-rule="evenodd" d="${ed}"/>`);

  const defs = gradient ? `<defs>${gradientDefs(m, s)}</defs>` : '';
  return `<svg xmlns="http://www.w3.org/2000/svg" width="${size.width}" height="${size.height}" viewBox="0 0 ${total} ${total}" color-interpolation="sRGB">${defs}${parts.join('')}</svg>`;
}
```

```ts
import jsQR from 'jsqr';

export interface VerifyResult {
  ok: boolean;
  decoded: string | null;
}

/** rgba: non-premultiplied RGBA (canvas getImageData layout). */
export function verifyRgba(
  rgba: Uint8Array | Uint8ClampedArray, width: number, height: number, expected: string,
): VerifyResult {
  // Transparent exports are meant for light surfaces, so judge them on white.
  const px = new Uint8ClampedArray(rgba.length);
  for (let i = 0; i < rgba.length; i += 4) {
    const a = rgba[i + 3] / 255;
    px[i] = rgba[i] * a + 255 * (1 - a);
    px[i + 1] = rgba[i + 1] * a + 255 * (1 - a);
    px[i + 2] = rgba[i + 2] * a + 255 * (1 - a);
    px[i + 3] = 255;
  }
  // Not every phone reader handles inverted codes, so don't let the check be more lenient than them.
  const res = jsQR(px, width, height, { inversionAttempts: 'dontInvert' });
  const decoded = res ? new TextDecoder().decode(new Uint8Array(res.binaryData)) : null;
  return { ok: decoded === expected, decoded };
}
```

```ts
import type { Style } from './settings';

export type ContrastLevel = 'good' | 'ok' | 'low';
export interface ColorReport {
  minContrast: number;
  level: ContrastLevel;
  inverted: boolean;
  printVivid: boolean;
}

function rgb(hex: string): [number, number, number] {
  const n = parseInt(hex.slice(1), 16);
  return [(n >> 16) & 255, (n >> 8) & 255, n & 255];
}

function linear(c: number): number {
  const s = c / 255;
  return s <= 0.04045 ? s / 12.92 : ((s + 0.055) / 1.055) ** 2.4;
}

export function luminance(hex: string): number {
  const [r, g, b] = rgb(hex).map(linear);
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}

export function contrastRatio(a: string, b: string): number {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x);
  return (hi + 0.05) / (lo + 0.05);
}

/** Rough "neon" detector: very saturated + very bright colours fall outside typical CMYK gamut. */
export function isVivid(hex: string): boolean {
  const [r, g, b] = rgb(hex).map((c) => c / 255);
  const max = Math.max(r, g, b);
  const min = Math.min(r, g, b);
  const s = max === 0 ? 0 : (max - min) / max;
  return s > 0.85 && max > 0.85;
}

export function analyzeColors(s: Style): ColorReport {
  const darks = [s.color1];
  if (s.fillMode !== 'solid') darks.push(s.color2);
  if (s.eyeColorEnabled) darks.push(s.eyeColor);
  const bg = s.bgTransparent ? '#ffffff' : s.bgColor;

  const minContrast = Math.min(...darks.map((d) => contrastRatio(d, bg)));
  const level: ContrastLevel = minContrast >= 7 ? 'good' : minContrast >= 4 ? 'ok' : 'low';
  const inverted = darks.some((d) => luminance(d) > luminance(bg));
  const printed = s.bgTransparent ? darks : [...darks, bg];
  return { minContrast, level, inverted, printVivid: printed.some(isVivid) };
}
```

```ts
const SIGNATURE = new Uint8Array([137, 80, 78, 71, 13, 10, 26, 10]);
const COLOR_TYPES = new Set(['sRGB', 'gAMA', 'cHRM', 'iCCP', 'pHYs']);

const CRC_TABLE = (() => {
  const t = new Uint32Array(256);
  for (let n = 0; n < 256; n++) {
    let c = n;
    for (let k = 0; k < 8; k++) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;
    t[n] = c >>> 0;
  }
  return t;
})();

export function crc32(bytes: Uint8Array): number {
  let c = 0xffffffff;
  for (const b of bytes) c = CRC_TABLE[(c ^ b) & 0xff] ^ (c >>> 8);
  return (c ^ 0xffffffff) >>> 0;
}

export interface Chunk {
  type: string;
  data: Uint8Array;
}

export function readChunks(png: Uint8Array): Chunk[] {
  if (png.length < 8 || SIGNATURE.some((b, i) => png[i] !== b)) throw new Error('not a PNG');
  const view = new DataView(png.buffer, png.byteOffset, png.byteLength);
  const out: Chunk[] = [];
  let p = 8;
  while (p + 12 <= png.length) {
    const len = view.getUint32(p);
    const type = String.fromCharCode(...png.subarray(p + 4, p + 8));
    out.push({ type, data: png.slice(p + 8, p + 8 + len) });
    p += 12 + len;
  }
  return out;
}

function encodeChunk({ type, data }: Chunk): Uint8Array {
  const out = new Uint8Array(12 + data.length);
  const view = new DataView(out.buffer);
  view.setUint32(0, data.length);
  for (let i = 0; i < 4; i++) out[4 + i] = type.charCodeAt(i);
  out.set(data, 8);
  view.setUint32(8 + data.length, crc32(out.subarray(4, 8 + data.length)));
  return out;
}

export function writeChunks(chunks: Chunk[]): Uint8Array {
  const parts = [SIGNATURE, ...chunks.map(encodeChunk)];
  const out = new Uint8Array(parts.reduce((n, p) => n + p.length, 0));
  let o = 0;
  for (const p of parts) {
    out.set(p, o);
    o += p.length;
  }
  return out;
}

function u32s(...ns: number[]): Uint8Array {
  const b = new Uint8Array(ns.length * 4);
  const v = new DataView(b.buffer);
  ns.forEach((n, i) => v.setUint32(i * 4, n));
  return b;
}

/** Tag the image as sRGB (plus gAMA/cHRM for readers that ignore sRGB); optionally set print DPI. */
export function applyColorMetadata(png: Uint8Array, dpi?: number): Uint8Array {
  const chunks = readChunks(png).filter((c) => !COLOR_TYPES.has(c.type));
  const meta: Chunk[] = [
    { type: 'sRGB', data: new Uint8Array([0]) }, // perceptual intent
    { type: 'gAMA', data: u32s(45455) },
    { type: 'cHRM', data: u32s(31270, 32900, 64000, 33000, 30000, 60000, 15000, 6000) },
  ];
  if (dpi) {
    const ppm = Math.round(dpi / 0.0254);
    const d = new Uint8Array(9);
    const v = new DataView(d.buffer);
    v.setUint32(0, ppm);
    v.setUint32(4, ppm);
    d[8] = 1; // unit: metre
    meta.push({ type: 'pHYs', data: d });
  }
  const ihdr = chunks.findIndex((c) => c.type === 'IHDR');
  chunks.splice(ihdr + 1, 0, ...meta);
  return writeChunks(chunks);
}
```

```ts
import type { SvgSize } from './render';
import type { Style } from './settings';

export const PRINT_DPI = 300;

export function physicalSize(px: number, dpi = PRINT_DPI) {
  const inches = px / dpi;
  return { cm: inches * 2.54, mm: inches * 25.4 };
}

export function svgSizeAttrs(s: Style): SvgSize {
  if (s.target === 'print') {
    const mm = `${physicalSize(s.exportSize).mm.toFixed(1)}mm`;
    return { width: mm, height: mm };
  }
  return { width: String(s.exportSize), height: String(s.exportSize) };
}

export function defaultFileName(text: string, kind: 'png' | 'svg'): string {
  try {
    const host = new URL(text).hostname;
    if (host) return `qr-${host}.${kind}`;
  } catch {
    // not a URL
  }
  return `qr.${kind}`;
}

export interface ExportDeps {
  saveDialog(o: { defaultPath: string; filters: { name: string; extensions: string[] }[] }): Promise<string | null>;
  writeBytes(path: string, data: Uint8Array): Promise<void>;
  writeText(path: string, data: string): Promise<void>;
}

export async function exportFile(
  deps: ExportDeps,
  kind: 'png' | 'svg',
  defaultPath: string,
  make: () => Promise<Uint8Array | string>,
): Promise<'saved' | 'cancelled'> {
  const path = await deps.saveDialog({
    defaultPath,
    filters: [{ name: kind.toUpperCase(), extensions: [kind] }],
  });
  if (!path) return 'cancelled';
  const content = await make();
  if (typeof content === 'string') await deps.writeText(path, content);
  else await deps.writeBytes(path, content);
  return 'saved';
}
```

```ts
/** Render an SVG string (already sized at px×px) onto a canvas. */
export async function svgToCanvas(svg: string, px: number): Promise<HTMLCanvasElement> {
  const url = URL.createObjectURL(new Blob([svg], { type: 'image/svg+xml' }));
  try {
    const img = new Image();
    img.src = url;
    await img.decode();
    const canvas = document.createElement('canvas');
    canvas.width = canvas.height = px;
    const ctx = canvas.getContext('2d');
    if (!ctx) throw new Error('2D canvas unavailable');
    ctx.drawImage(img, 0, 0, px, px);
    return canvas;
  } finally {
    URL.revokeObjectURL(url);
  }
}

export function canvasRgba(canvas: HTMLCanvasElement) {
  const ctx = canvas.getContext('2d')!;
  const { data, width, height } = ctx.getImageData(0, 0, canvas.width, canvas.height);
  return { rgba: data, width, height };
}

export async function canvasToPngBytes(canvas: HTMLCanvasElement): Promise<Uint8Array> {
  const blob = await new Promise<Blob>((resolve, reject) =>
    canvas.toBlob((b) => (b ? resolve(b) : reject(new Error('PNG encoding failed'))), 'image/png'),
  );
  return new Uint8Array(await blob.arrayBuffer());
}
```

```ts
const VERIFY_PX = 512;
let matrix: QrMatrix | null = null;
let lastVerify: VerifyResult | null = null;
let verifyToken = 0;
let verifyTimer: number | undefined;

function setStatus(kind: 'ok' | 'fail' | 'pending' | 'idle', msg: string) {
  const el = $('status');
  el.dataset.kind = kind;
  el.textContent = msg;
}

function setExportEnabled(on: boolean) {
  $<HTMLButtonElement>('savePng').disabled = !on;
  $<HTMLButtonElement>('saveSvg').disabled = !on;
}

function renderWarnings(list: string[]) {
  const ul = $('warnings');
  ul.replaceChildren(...list.map((w) => Object.assign(document.createElement('li'), { textContent: w })));
}

function scheduleVerify(m: QrMatrix, s: Style, text: string) {
  clearTimeout(verifyTimer);
  const token = ++verifyToken;
  verifyTimer = window.setTimeout(async () => {
    let result: VerifyResult;
    try {
      const canvas = await svgToCanvas(renderSvg(m, s, { width: String(VERIFY_PX), height: String(VERIFY_PX) }), VERIFY_PX);
      const { rgba, width, height } = canvasRgba(canvas);
      result = verifyRgba(rgba, width, height, text);
    } catch (err) {
      console.error(err);
      if (token === verifyToken) { lastVerify = { ok: false, decoded: null }; setStatus('fail', t('statusError')); }
      return;
    }
    if (token !== verifyToken) return; // a newer edit superseded this check
    lastVerify = result;
    setStatus(result.ok ? 'ok' : 'fail', t(result.ok ? 'statusOk' : 'statusFail'));
  }, 150);
}

function update() {
  saveSettings(storage, settings);
  const s = settings.style;
  document.body.dataset.fill = s.fillMode;
  $<HTMLInputElement>('eyeColor').disabled = !s.eyeColorEnabled;
  $<HTMLInputElement>('bgColor').disabled = s.bgTransparent;
  $('marginValue').textContent = String(s.margin);
  $('targetDesc').textContent = t(s.target === 'print' ? 'targetPrintDesc' : 'targetScreenDesc');
  $('physical').textContent = s.target === 'print'
    ? t('physical', { px: s.exportSize, cm: physicalSize(s.exportSize).cm.toFixed(1), dpi: PRINT_DPI })
    : '';
  $('exportMsg').textContent = '';

  const text = normalizeText(settings.text);
  matrix = null;
  lastVerify = null;
  try {
    matrix = encode(text, s.ecc);
  } catch (e) {
    clearTimeout(verifyTimer);
    verifyToken++;
    $('preview').replaceChildren();
    setStatus(e instanceof TooLongError ? 'fail' : 'idle', t(e instanceof TooLongError ? 'statusTooLong' : 'statusEmpty'));
    setExportEnabled(false);
    renderWarnings([]);
    return;
  }

  $('preview').innerHTML = renderSvg(matrix, s, { width: '100%', height: '100%' });
  setExportEnabled(true);

  const report = analyzeColors(s);
  $<HTMLMeterElement>('contrastMeter').value = report.minContrast;
  const levelKey = report.level === 'good' ? 'contrastGood' : report.level === 'ok' ? 'contrastOk' : 'contrastLow';
  $('contrastValue').textContent = `${report.minContrast.toFixed(1)}:1 · ${t(levelKey)}`;

  const warnings: string[] = [];
  if (report.inverted) warnings.push(t('warnInverted'));
  else if (report.level === 'low') warnings.push(t('warnLowContrast'));
  if (s.margin < 2) warnings.push(t('warnMargin'));
  if (s.bgTransparent) warnings.push(t('warnTransparent'));
  if (s.target === 'print' && report.printVivid) warnings.push(t('warnVivid'));
  renderWarnings(warnings);

  setStatus('pending', t('statusChecking'));
  scheduleVerify(matrix, structuredClone(s), text);
}

async function doExport(kind: 'png' | 'svg') {
  if (!matrix) return;
  const m = matrix;
  const s = structuredClone(settings.style);
  const text = normalizeText(settings.text);
  if (lastVerify?.ok !== true) {
    const go = await ask(t('confirmExportMsg'), { title: t('confirmExportTitle'), kind: 'warning' });
    if (!go) return;
  }
  const make = kind === 'png'
    ? async () => {
        const px = s.exportSize;
        const canvas = await svgToCanvas(renderSvg(m, s, { width: String(px), height: String(px) }), px);
        return applyColorMetadata(await canvasToPngBytes(canvas), s.target === 'print' ? PRINT_DPI : undefined);
      }
    : async () => `<?xml version="1.0" encoding="UTF-8"?>\n${renderSvg(m, s, svgSizeAttrs(s))}\n`;
  try {
    const outcome = await exportFile(deps, kind, defaultFileName(text, kind), make);
    $('exportMsg').textContent = outcome === 'saved' ? t('saved') : '';
  } catch (err) {
    $('exportMsg').textContent = t('exportError', { msg: err instanceof Error ? err.message : String(err) });
  }
}

}

  const el = $<HTMLSelectElement>(key);

}

  setLang(settings.lang);
```
